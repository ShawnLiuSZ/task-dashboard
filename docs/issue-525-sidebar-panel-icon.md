# 收起侧边栏按钮的图标换成「侧栏面板」形状 — #525

> 用户给了一张图标截图（**圆角矩形 + 左侧竖分隔线**），要求把顶栏的收起侧边栏按钮
> **换成这个图标**。

## 为什么要「固定」而不是随状态翻转

原实现是「‹ / ›」箭头**随状态翻转**（展开态 `‹`、折叠态 `›`）。换成面板图标后：

- **面板形状本身就表达「侧栏」** —— 比箭头更直观；
- 箭头会让人误以为是「往左 / 往右移动窗口」，而不是「收起 / 展开侧栏」；
- 展开 / 收起的状态由**侧栏宽度本身**（200px ↔ 56px）体现，不需要图标再表达一遍；
- hover 的 `title` / `aria-label` 已说明当前点击会做什么。

⇒ **固定图标**，动作靠 tooltip 说明（VS Code 的 toggle-sidebar 也是固定图标）。

## 图形的复刻方式（按用户截图**逐像素反推**）

用户原图的墨迹 bbox = **16×14 px**，逐行扫描（阈值 < 200）得到：

```
y= 14: 39-47                 ← 顶边（圆角处）
y= 15: 36-49
y= 16: 36-37  48-49          ← 只有左右边框
y= 17: 35-36  38-39  49-49   ← 左边框 35-36 ｜ 竖线 38-39 ｜ 右边框 49
y= 18..23: 35-36  38-39  49-50
y= 24: 36-36  38-39  49-50
y= 25: 36-37  48-49
y= 26: 36-49
y= 27: 38-46                 ← 底边（圆角处）
```

⇒ 关键特征：**左边框与竖分隔线是两条独立的线，中间留 1px 细缝**（不是「实心侧栏」），
且竖线**紧贴左边框**（距左边框中心仅 3 px）。

| 特征 | 实测（16×14 源图） | 24×24 viewBox 取值 |
|---|---|---|
| 外框（描边中心） | x 35.5..49.5、y 14.5..26.5 | x 4..20、y 4..20 |
| 圆角半径 | ≈ 3.5 px（占框高 1/3） | r = 5 |
| 竖分隔线（描边中心） | x = 38.5 ⇒ 距左边框中心 3 px | x = 7 |
| 竖线与左边框 | **留 1 px 细缝**（不相连） | 天然不相连 |
| 竖线长度 | 6 px（占框高 60%） | y 7.5..16.5 |

最终 path（两条 stroke 子路径）：

```
M9 4h6a5 5 0 0 1 5 5v6a5 5 0 0 1-5 5H9a5 5 0 0 1-5-5V9a5 5 0 0 1 5-5z   ← 外框（圆角矩形）
M7 7.5v9                                                                            ← 左侧竖分隔线
```
