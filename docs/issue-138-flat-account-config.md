# Issue #138: 设置页自定义列映射改为平铺卡片

## 背景 / 动机

多账号场景下，两处账号下拉切换繁琐，无法一眼看到所有账号配置。

## 设计 / 方案

### 架构变更

- 去掉两处账号下拉 select（`bmAccountId`、`colAccountId`）
- 所有账号一次性平铺为卡片列表
- 每张卡片独立管理：看板模式 + 自定义列配置

### 卡片结构

```
┌─ 账号名 ★ ──────────────────────────────────────┐
│ 看板模式: [Project 状态列 ▼]                       │
│                                                    │
│ （若 custom 模式）                                  │
│ 自定义列:                                          │
│ ┌─ 列名 ───────────────────────────────────────┐  │
│ │ chips: Status1  🗑  Status2  🗑               │  │
│ │ [编辑] [删除]                                 │  │
│ └──────────────────────────────────────────────┘  │
│ [+ 添加列] [保存]                                  │
└────────────────────────────────────────────────────┘
```

### State 重构

- 删除 `bmAccountId`、`bmMode`、`colAccountId`、`columns`、`editingCol` 等全局状态
- 新增 `accountStates: Record<number, AccountEditState>` — 每个账号独立维护

### 后端

零改动。所有 API 签名不变。

## 接口 / 行为变更

- 设置面板「自定义列映射」tab 改为卡片平铺布局
- 每个账号可独立切换看板模式、编辑自定义列
- 初始化时一次性加载所有账号的列配置

## 测试 / 验收

1. 打开设置 → 自定义列映射 tab → 所有账号平铺显示
2. 每个账号卡片：看板模式下拉可独立切换
3. custom 模式下展开自定义列列表 + 添加/编辑/删除
4. `npx tsc --noEmit` 通过
